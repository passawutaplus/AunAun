# Event scout — official sources

The weekly scout checks these first. Categories don't matter here: any of them can post an
exhibition, workshop, art fair, talk, open call or other event.

## Policy — original source first

1. Take event details only from the organiser or the venue that runs the event.
2. Media sites and event aggregators are for discovery only, never the `source_url`.
3. Gallery, museum and organiser websites come first; official Facebook pages are a fallback.
4. Found it through a third party? Find the original announcement before proposing it.
5. Copy title, dates, venue, organiser and registration link from the original.
6. Every event keeps its original link in `source_url`.
7. If the gallery only rents out the space, trace the real organiser.
8. Everything lands as a draft; the SAMECOR team approves before it goes live.
