# Event scout — official sources

The weekly scout checks these first. Categories don't matter here: any of them can post an
exhibition, workshop, art fair, talk, open call or other event.

## Policy — original source first

1. Take event details only from the organiser or the venue that runs the event.
2. Media sites and event aggregators are for discovery only, never the `source_url`.
3. Gallery, museum and organiser websites come first; official Facebook pages are a fallback.
4. Found it through a third party? Find the original announcement before proposing it.
5. Copy title, dates, venue, organiser and registration link from the original.
6. Every event keeps its original link in `source_url`.
7. If the gallery only rents out the space, trace the real organiser.
8. Confirmed events are published directly (owner decision 2026-11-27); anything uncertain lands
   as a draft for the team. The owner reviews after the fact and asks for edits or removal.
9. A cover picture is only ever the event's official poster from the organiser's or venue's own page.

Each run, start with the Facebook home feed and these groups (newest posts), then check the organiser pages.

How: Facebook's event search is weak for Thai places. Use post search (`/search/posts/?q=<event name>`)
to verify a known lead, then read the organiser's own post or event (`/<page>/upcoming_hosted_events`).
Use the post or event permalink as `source_url`. Leave Facebook pictures out: their links are long and expire.

Discovery only (never `source_url`): TAT newsroom / thailand.go.th event listings, contest
aggregators (Contest Thailand, thaiprize, Bounty Hunter), Time Out, news sites. Most provincial
events are announced only on Facebook: confirm the page from the organiser's website first.
