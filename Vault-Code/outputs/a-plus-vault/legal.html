คุกกี้และการเก็บข้อมูลในเบราว์เซอร์ · Cookies and browser storage

เราไม่ตั้งคุกกี้เลย แอปใช้ localStorage/sessionStorage เฉพาะเรื่องที่คุณสั่ง เช่น การเข้าสู่ระบบ รายการที่บันทึก ธีม ไม่มีคุกกี้โฆษณา ไม่มีตัวติดตามบุคคลที่สาม ฟอนต์โฮสต์เอง ภาพจากลิงก์ที่คุณบันทึกโหลดจากเว็บต้นทางโดยไม่ส่ง referrer (การดูภาพนั้นย่อมติดต่อเว็บต้นทาง) ภาพใน Discover เก็บสำเนาไว้เองจึงไม่ติดต่อเว็บอื่น

เพราะไม่มีรายการที่ต้องขอความยินยอม จึงไม่แสดงแบนเนอร์คุกกี้ หากในอนาคตเพิ่มสถิติหรือสิ่งที่ต้องขอความยินยอม จะแสดงตัวเลือก "ยอมรับทั้งหมด / ปฏิเสธที่ไม่จำเป็น / เลือกเอง" โดยไม่โหลดอะไรก่อนคุณเลือก และเคารพสัญญาณ Global Privacy Control

We set no cookies. The app uses localStorage/sessionStorage only for what you asked for (login, saved items, theme). No advertising cookies, no third-party trackers, self-hosted fonts. Images of links you save load from the source site without a referrer (viewing them contacts that site); Discover images are re-hosted by us.

Because nothing requires consent, no cookie banner is shown. If analytics or anything consent-requiring is ever added, you will get Accept all / Reject non-essential / Choose, nothing loads before your choice, and Global Privacy Control is respected. Change choices any time in Settings > Privacy.

ความปลอดภัย · Security overview

เนื้อหาเป็นส่วนตัวโดยค่าเริ่มต้น ใช้ Row Level Security บนฐานข้อมูล ไม่มีคีย์ฝั่งเซิร์ฟเวอร์ในส่วนขยายหรือเว็บ ตรวจชนิดและขนาดไฟล์ ลบข้อมูลตำแหน่ง (EXIF GPS) จากรูปที่อัปโหลด ใช้ HTTPS/HSTS และ Content-Security-Policy

เก็บในเครื่อง: โทเค็นเชื่อมต่อ การตั้งค่า รายการล่าสุด คิวส่งซ้ำ (สูงสุด 50) กดตัดการเชื่อมต่อเพื่อล้าง ส่วนขยายไม่ตั้งคุกกี้ ไม่โหลดโค้ดหรือฟอนต์ภายนอก ไม่ขอสิทธิ์ tabs สิทธิ์ที่ใช้: contextMenus, activeTab, storage, scripting, alarms และสิทธิ์เข้าถึงเฉพาะโดเมน A+ Vault หากเปิด "ตรวจจับรูปภาพอัจฉริยะบนทุกเว็บ" จะขอสิทธิ์ทุกเว็บครั้งเดียว ปิดได้ทุกเมื่อ

It acts only when you choose: right-click "+ Keep in Vault" or "Keep all images", Snapshot, popup buttons, Alt+Shift+K. Data sent: page URL and title, the image/video/link URL you chose, title, note, #tags, collection, credit/source data found on the page (creator, site name, licence link: stored as information, never as a granted licence), and the cropped image for Snapshot. "Keep all" sends URLs, not image files.

Stored on your device: connection token, settings, recent captures, retry queue (max 50); Disconnect clears it. The extension sets no cookies, loads no remote code or fonts and does not request the tabs permission. Permissions: contextMenus, activeTab, storage, scripting, alarms, and access to A+ Vault domains only. If you turn on "Smart image detection on all sites" it asks for all-sites access once; you can turn it off any time.
