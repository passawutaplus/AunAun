## 2. ปกคอลลาจ (Cover)

- ไฟล์ `public/journal/<slug>-cover.jpg` · 16:9 · กว้าง 1600px · JPEG คุณภาพ ~74 (ไม่เกิน ~300 KB)
- สไตล์ (คงที่ทุกเรื่อง):
  - พื้นกระดาษ Studio White `#F8F7F2`
  - ภาพตัดแปะขาวดำ เม็ด halftone / risograph ขอบกระดาษฉีก เงาซ้อนกระดาษบางๆ
  - สีแดง `#EE3D29` เฉพาะเส้นวาดมือ 1 เส้น + ✱ 1 จุด (ไม่เกิน ~10% ของภาพ)
  - เว้นพื้นที่ว่างเยอะ · ไม่มีตัวหนังสือในภาพ · ไม่มีโลโก้
- ที่มา: AI ช่วยสร้างได้ (เป็นภาพบรรยากาศ) แต่ **ห้ามใช้ AI แทนผลงานของครีเอเตอร์จริง** — ถ้าบทความพูดถึงผลงานของใคร ใช้ภาพจริงที่ได้รับอนุญาต
- เครดิตปก: `Illustration: SAMECOR (AI-assisted collage)`
- Prompt ตั้งต้น (เปลี่ยนเฉพาะวัตถุตัดแปะให้ตรงเรื่อง):

```
Editorial cut-paper collage cover on warm off-white paper background (#F8F7F2).
Black-and-white halftone photo cut-outs: <วัตถุ 3–4 อย่างที่เล่าเรื่องนี้>.
Thin hand-drawn red (#EE3D29) outline <ทำหน้าที่อะไรในเรื่อง>, one small red asterisk accent, red used sparingly.
Visible paper edges, soft layered paper shadows, natural soft daylight, risograph halftone texture.
Minimal, gallery-calm, contemporary editorial magazine style, generous white space.
No text, no letters, no logos.
```

## 3. ภาพและกราฟิกในเนื้อหา

| บล็อก | ใช้เมื่อ | ไฟล์ | กติกา |
|---|---|---|---|
| `{ img: { src, alt, caption?, credit } }` | ภาพถ่ายจริง: คน สถานที่ ผลงาน | `public/journal/<slug>*.jpg` กว้าง ≤1800px | เครดิตทุกภาพ · ผลงานครีเอเตอร์ต้องได้รับอนุญาตเป็นลายลักษณ์อักษร |
| `{ graphic: { src, alt, caption? } }` | อธิบายหลักการ ลำดับ หรือการเปลี่ยนแปลง | `public/journal/graphics/<name>.svg` | ทำเอง ไม่ใช้เครดิต (ดูด้านล่าง) |

กราฟิก / Motion graphic (SVG ทำเอง):
- สีเฉพาะ `#F8F7F2` `#282929` `#666666` `#E6E6E3` + แดง `#EE3D29` เป็นจุดเน้นจุดเดียว
- ไม่มีตัวหนังสือใน SVG (อธิบายใน caption แทน) — ถ้าจำเป็นต้องมี ให้แปลงเป็น outline
- เคลื่อนไหวด้วย CSS/SMIL ใน SVG เท่านั้น (ไม่มี JS) · วนลูปช้าๆ 6–8 วินาที · ต้องมี `@media (prefers-reduced-motion: reduce)` ที่หยุดและโชว์สถานะสุดท้าย
- ใส่ `role="img"` + `aria-label` ภาษาไทยใน SVG และ `alt` ในบล็อก
- ตัวอย่างที่มีแล้ว: `proximity.svg` (จัดกลุ่มด้วยระยะห่าง) · `story-arc.svg` (โครงเรื่อง 4 ท่อน) · `gaze-path.svg` (ลำดับการมอง)

ตำแหน่ง: กราฟิกวางต่อจากย่อหน้าที่อธิบายหลักการนั้นทันที · ภาพจริงวางกลางบทความเพื่อพักสายตา · ไม่วางภาพติดกัน 2 ภาพ

## 4. แหล่งอ้างอิง (บังคับ)

- `sources: [{ title, publisher, url }]` อย่างน้อย 2 แหล่ง เรียงจากสำคัญสุด
- หน้าเว็บโชว์ 2 แหล่งแรก ที่เหลือพับใต้ "ดูแหล่งอ้างอิงเพิ่มเติม (N)" — ไม่ให้ยาวรก
- ใช้แหล่งที่เชื่อถือได้: องค์กรวิจัย/มาตรฐาน (NN/g, W3C) · พิพิธภัณฑ์/สถาบันการศึกษา · สื่อในวงการที่มีชื่อ
- URL ต้องมีอยู่จริงและตรงกับเนื้อหาที่อ้าง ห้ามเดา URL
- แหล่งเดียวกันนี้ไปอยู่ใน Article JSON-LD (`citation`) และ HTML สำหรับบอทโดยอัตโนมัติ

## 5. เช็กลิสต์ก่อนขึ้นเว็บ

1. ผลงาน/เนื้อหาเด่นกว่าแบรนด์ไหม · แดงอยู่แค่จุดสนใจไหม · ไม่สัญญาเกินจริงใช่ไหม
2. สะกด SAMECOR ถูก (ไม่ใช่ SameCor/Samecore)
3. ปก + ภาพในเนื้อหามี alt และเครดิตครบ
4. แหล่งอ้างอิง ≥2 และลิงก์เปิดได้
5. `datePublished` เป็นเวลาไทย (+07:00) · slug เป็นอังกฤษตัวเล็กคั่นด้วย -
