# Code review & cleanup — 7 Oct 2026

Branch `fix/review-2026-10-07` (PR #28). Companion: [`db-drift-2026-10-07.md`](./db-drift-2026-10-07.md).

## Rules that came out of this review

1. **Database changes only via `Solo-Code/supabase/migrations/`.** The old Anthem folder is
   `supabase/legacy-migrations-NOT-APPLIED/` (reference only). Direct-apply scripts were removed.
2. **Types are the early-warning system.** Regenerate with `scripts/db-types/README.md`; a TypeScript
   error on a table, column or RPC name means the DB and the app disagree. Several runtime bugs fixed here
   (`collab_requests.timeline`, `collections.user_id`, `inspire_boards.title`, status `"ใหม่"`) were
   visible as type errors that CI ignored.
3. **Typecheck status:** 1,221 → 256 errors (CI now fails if it goes up: `typecheck-baseline.json`). Most remaining ones are the 14 tables / 31 functions
   the DB lacks (see drift doc) plus a few loosely typed admin hooks.
4. **Money is computed on the server** (`api/hire-charge.js`, `omise-webhook.js`, `hire_orders_money_guard`).
5. **Helpers live in one place:** `lib/format.ts` (`timeAgo`, `bangkokYmd`, `clampStr`, THB/date formatting).
6. **Motion:** page transition is opacity-only (a transform on the page wrapper breaks `position: fixed`
   children); route changes use React `startTransition` so a lazy route never flashes the full-screen loader.
   Scroll handlers must be rAF-throttled and write to the DOM via refs, not state.
