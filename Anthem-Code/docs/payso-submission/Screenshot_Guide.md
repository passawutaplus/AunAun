# คู่มือถ่ายภาพหน้าจอสำหรับเอกสาร Payso

ใช้คู่กับ `Payso_Submission_Pack.pdf` (ไฟล์ต้นฉบับ `Payso_Submission_Pack.html`) · ภาพแต่ละภาพมีรหัส `F-xx` ตรงกับกรอบ “แทรกภาพ” ในเอกสาร
ตั้งชื่อไฟล์ภาพเป็น `F-20.png`, `F-21.png` … เก็บในโฟลเดอร์เดียว แล้วส่งทั้งโฟลเดอร์ + ไฟล์ HTML ให้ Claude Design วางภาพลงกรอบให้ได้

> **ห้ามถ่ายด้วยข้อมูลจริงของคนอื่น** · ปิดทับ (แถบสีดำ) เลขบัตร เลขบัญชี ที่อยู่ เบอร์โทร ใบหน้า และอีเมลลูกค้าจริงทุกครั้ง · ใช้บัญชีทดสอบ 2 บัญชี (ผู้ขาย / ผู้ซื้อ)

---

## 0. เตรียมก่อนถ่าย

### 0.1 ภาพที่ถ่ายได้ทันทีบนเว็บจริง (ไม่ต้องตั้งค่าอะไร)
F-02, F-16, F-40, F-50–F-53 — หน้า public ล้วน ๆ

### 0.2 ภาพที่ต้องมีระบบชำระเงินโหมดทดสอบ (F-20 ถึง F-36)
ต้องใช้ **Vercel Preview** ของ branch นี้ ไม่ใช่เว็บจริง เพราะเว็บจริงปิดปุ่มชำระเงินไว้โดยตั้งใจ

ตั้งค่า Environment Variables ของ **Preview** บน Vercel:

| ตัวแปร | ค่า |
|---|---|
| `VITE_APLUS1_FULL_PRODUCT` | `true` |
| `VITE_APLUS1_PAYMENTS_ENABLED` | `true` |
| `VITE_OMISE_CHARGES_ENABLED` | `true` |
| `VITE_OMISE_MODE` / `OMISE_MODE` | `test` |
| `OMISE_SECRET_KEY` | คีย์ทดสอบขึ้นต้น `skey_test_…` (ห้ามใส่คีย์ live) |
| `OMISE_PUBLIC_KEY` / `VITE_OMISE_PUBLIC_KEY` | คีย์ทดสอบขึ้นต้น `pkey_test_…` |
| `OMISE_WEBHOOK_SECRET` | secret ของ webhook ฝั่งทดสอบ |
| `PAYMENT_PROVIDER` | `omise` |
| `SUPABASE_SERVICE_ROLE_KEY` | คีย์ **ใหม่** หลังหมุน (ฝั่งเซิร์ฟเวอร์เท่านั้น) |
| `CRON_SECRET` | สุ่มสตริงยาว ๆ |

ตั้ง webhook ใน Dashboard ผู้ให้บริการ (โหมดทดสอบ) ให้ชี้ `https://<preview-url>/api/omise-webhook`

**ข้อควรรู้**
- Preview ใช้ฐานข้อมูลเดียวกับเว็บจริง → ออเดอร์ทดสอบจะอยู่ในฐานข้อมูลจริง ตั้งชื่องานว่า `[TEST] …` และลบทิ้งหลังถ่ายเสร็จ
- ก่อนทดสอบต้องรัน SQL ชุด `apply-2026-10-09` (รวมข้อ 08 ที่ปิดโหมดจ่ายเงินปลอม) เสียก่อน ไม่งั้นจะเห็นช่องทางจ่ายเงินปลอมในฐานข้อมูล
- โหมดทดสอบ: จ่ายสำเร็จโดยกด “mark as paid” ใน Dashboard ของผู้ให้บริการ (ฝั่งทดสอบ) หรือผ่านปุ่มทดสอบในแอปถ้ามี — ไม่มีการตัดเงินจริง
- ต้องมีบัญชี 2 บัญชี: **ผู้ขาย** (มีโปรไฟล์ แพ็กเกจ และผ่าน KYC สำหรับขั้นถอนเงิน) และ **ผู้ซื้อ** (สมัครใหม่)

### 0.3 ภาพ KYC (F-10 ถึง F-14)
ใช้บัญชีทดสอบแยก **อย่าส่งเอกสารจริงขึ้นเว็บจริงเพื่อถ่ายภาพ** · กรอกค่าทดสอบ (ชื่อสมมติ เลขบัตรผ่านการตรวจหลักตรวจเท่านั้น ห้ามใช้เลขของคนจริง) · ถ่ายหน้าจอได้โดยไม่ต้องกดส่งขั้นสุดท้าย

## 2. ส่งให้ Claude Design ช่วยจัดหน้า
1. ส่ง `Payso_Submission_Pack.html` + โฟลเดอร์ภาพ `F-xx.png`
2. สั่งว่า: “วางภาพตามรหัสลงกรอบ ‘แทรกภาพ F-xx’ ในเอกสาร ย่อภาพให้พอดีหน้า A4 คงข้อความเดิมทุกตัวอักษร และส่งออกเป็น PDF”
3. ตรวจก่อนส่ง Payso: ช่องสีเหลือง `[…]` กรอกครบ · ไม่มีเลขบัตร/เลขบัญชี/ใบหน้าหลงเหลือ · ข้อมูลทุกจุดตรงกับเว็บจริง
