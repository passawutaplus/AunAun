# บอทแคปภาพสำหรับเอกสาร Payso

บอทขับ Edge (Playwright) แคปภาพส่วนที่ต้องล็อกอินลงโฟลเดอร์ `docs/payso-submission/screenshots/` ตามรหัส F-xx ในเอกสาร
**บอทไม่สร้างบัญชีและไม่กรอกรหัสผ่านให้** — คุณสร้างบัญชีทดสอบและล็อกอินเองครั้งเดียว บอทใช้ session ที่บันทึกไว้

## ขั้นที่ 1 — สร้างบัญชีทดสอบและล็อกอิน (คุณทำ, ครั้งเดียวต่อบัญชี)
เปิด Terminal ที่โฟลเดอร์ `Anthem-Code` แล้วรัน (ทีละบัญชี):

```bash
node scripts/payso-capture/login.mjs seller
```

หน้าต่าง Edge จะเปิดที่หน้า `/auth` ของแอปในเครื่อง (สคริปต์เปิดเซิร์ฟเวอร์ให้เอง)
1. สมัครบัญชีทดสอบด้วย **อีเมล + รหัสผ่าน** (อย่าใช้ Google — เบราว์เซอร์อัตโนมัติมักถูกปฏิเสธ) ยืนยันอีเมลถ้าระบบขอ
2. ตั้งชื่อโปรไฟล์ให้ดูเป็นทดสอบ เช่น “ทดสอบ ผู้ขาย”
3. กลับมา Terminal กด Enter

| role | บัญชี | ใช้ถ่ายภาพ |
|---|---|---|
| `seller` | บัญชีครีเอเตอร์ทดสอบ | KYC (F-10–F-14), ส่งใบเสนอราคา, ส่งงาน, รายได้/ถอนเงิน |
| `buyer` | บัญชีผู้ซื้อทดสอบ | ขอจ้าง, ยอมรับใบเสนอราคา, ชำระเงิน, อนุมัติงาน |
| `admin` | บัญชีแอดมินของคุณ | หน้า KYC หลังบ้าน (F-15) — ใช้บัญชี email/password ของแอดมิน |

ไฟล์ session อยู่ใน `scripts/payso-capture/.auth/` (ไม่เข้า git) **ลบทิ้งเมื่อถ่ายเสร็จ**

## ขั้นที่ 2 — บอทแคปภาพ (ผมรันให้)
```bash
node scripts/payso-capture/capture-kyc.mjs            # F-10–F-13 กรอกข้อมูลสมมติ ไม่กดส่ง
node scripts/payso-capture/capture-kyc.mjs --submit   # + F-14 ส่งคำขอสมมติเข้าคิว (สร้างแถว pending 1 รายการ)
```
ข้อมูลที่บอทกรอกเป็นของสมมติทั้งหมด: ชื่อ “ทดสอบ ระบบ”, เลขบัตรที่สร้างให้ผ่านการตรวจหลักตรวจ (ไม่ใช่ของคนจริง), เอกสารเป็นภาพที่เขียนกำกับว่า SAMPLE

## ผลข้างเคียงที่ต้องเก็บกวาดหลังถ่าย (ฐานข้อมูลจริง)
- ไฟล์ตัวอย่างใน bucket `kyc-documents` ของบัญชีทดสอบ
- แถว `kyc_requests` / `kyc_documents` ของบัญชีทดสอบ (ถ้าใช้ `--submit`) และการแจ้งเตือนที่ส่งไปหาแอดมิน
- ออเดอร์/ข้อความ/ใบเสนอราคาทดสอบ (ขั้นสั่งซื้อ)
- บัญชีทดสอบเอง (ลบใน Supabase → Authentication → Users)
ผมจะเตรียม SQL เก็บกวาดให้เมื่อถ่ายเสร็จ
